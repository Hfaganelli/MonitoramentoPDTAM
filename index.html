Configurar acesso

Para adicionar produtos pelo painel, informe seu repositório e um token do GitHub. O token fica salvo só neste navegador.

Crie em github.com/settings/personal-access-tokens, só para este repositório, com permissão de leitura e escrita em Contents e Actions.
